# Tropical Digital Design System

## Direction

Warm, editorial, technical and restrained.

The design intentionally avoids:
- Purple/indigo startup gradients
- Generic white SaaS layouts
- Inter, Roboto and Arial
- Excessive rounded cards
- Sharp card-heavy layouts
- Neon glow effects
- Fake 3D dashboards
- Decorative AI-generated visual noise

## Typography

Display and body:
Bricolage Grotesque

Technical labels:
IBM Plex Mono

The combination creates a more editorial/engineering character without relying on common corporate defaults.

## Palette

The source company profile does not contain an approved brand palette or logo.

Therefore this implementation uses a provisional warm material-inspired palette rather than presenting it as official branding.

- Paper: #F3EFE7
- Deep paper: #E8E0D3
- Ink: #25231F
- Muted text: #706A60
- Line: #CFC6B8
- Copper: #A45135
- Deep copper: #713B2B
- Warm olive: #5D614D
- Off-white: #FBF9F4

The palette stays within one warm temperature family.

## Shape language

- Soft editorial corners on major containers
- Rounded-full buttons
- Thin borders
- No aggressive hard-edged card system
- Large asymmetrical whitespace

## Layout language

Prefer:
- Editorial asymmetric grids
- Large typography
- Long horizontal rules
- Numbered capability systems
- Layered circles and line diagrams
- Overlapping spatial cues
- Full-width tonal changes
- Variable section density

Avoid:
- Repeated three-column cards
- Alternating text/image sections
- Identical hero templates on every page

## Motion

Use one restrained entrance system:
- opacity + vertical reveal
- short stagger
- reduced-motion support

No continuous floating blobs or glowing particles.
